# 나의 AI 증권사

나만을 위한 증권사.

강의 대신 직접 짓는 'AI 6부서 증권사'. 매일 아침 AI 부서들이 관심종목을 분석하고 회의한 뒤,
결재 문서 한 장을 올립니다. 대표(나)는 읽고 **승인/보류**만 합니다.

## 회사 조직도

원칙은 하나입니다. **숫자는 코드가 정하고, 해석은 AI가 합니다.** 손절가를 AI에게 물으면 날마다 답이 바뀝니다.
"감정 제로"는 규칙을 코드로 박아 둘 때만 지켜집니다.

| 부서 | 누가 | 파일 | 하는 일 |
|---|---|---|---|
| 1. 스크리닝부 (SCAN) | 코드 | `aisec/setups.py` | 관심종목+시총 상위 20에서 5가지 셋업(돌파·눌림목·모멘텀·추세지속·반전) 판별 |
| 2. 분석부 (VERIFY) | AI | `.claude/agents/analysis-desk.md` | 셋업이 진짜인지 차트·실적·수급·백테스트로 검증 |
| 3. 마켓부 (REGIME) | 코드+AI | `aisec/market.py`, `market-desk.md` | 코스피 국면 판정, 오늘의 공격/중립/방어 태세 |
| 4. 리스크관리부 (GUARD) | 코드 | `aisec/risk.py` | 5기준(투자비중·총노출·손익비·최대손실·변동성) 통과/차단. **AI가 못 뒤집음** |
| 5. 운용부 (PLAN) | 코드 | `aisec/plan.py` | 진입 구간·손절가(-5%)·익절가(+10% 절반, +15% 나머지)·무효화 조건·손익비 |
| 6. 자가학습부 (LEARN) | 코드 | `aisec/backtest.py`, `aisec/review.py` | 3년 백테스트(승률·손익비·최대낙폭), 지난 계획 채점 |
| + 뉴스공시부 | AI | `news-desk.md` | 최근 7일 뉴스·공시 (출처 링크 필수) |
| + 반대편부 | AI | `redteam-desk.md` | 사면 안 되는 이유를 일부러 찾음 |
| 투자위원장 | AI | `.claude/skills/morning-brief` | 회의 진행, 결재 카드 작성 |

규칙은 `config.yaml` 한 파일에 있습니다. 관심종목, 시총 상위 몇 위까지 볼지, 손익비, 리스크 5기준 숫자, **본인 투자금(capital)**을 여기서 고칩니다.

## 처음 한 번만 할 일

1. **네트워크 열기** (Claude Code 클라우드 환경 설정 → Network access → Allowed domains)
   - `fchart.stock.naver.com`: 일봉 주가 (필수)
   - `data.krx.co.kr`: 시가총액 상위 20 순위, 수급, PER (없으면 관심종목 6개만 분석)
2. **KRX 무료 회원가입** (data.krx.co.kr), 환경 변수 `KRX_ID`, `KRX_PW` 등록
   (클라우드 환경 설정의 Environment variables). 없으면 수급·재무 부서는 "자료 없음"으로 보고합니다.
3. 동작 확인: `python -m pytest -q`, 그다음 `python -m aisec.cli`

## 매일 아침

Claude Code에 "아침 브리핑 해 줘". 예약 실행(Routine)으로 평일 07:30에 자동으로 돌게 할 수 있습니다.
결과는 `reports/<날짜>.md`.

## 모의투자

결재 카드를 보고 "삼성전자 승인"이라고 말하면 가상 매수가 장부(`paper/ledger.json`)에 올라갑니다.
다음 날 시가가 진입 구간 안이어야 체결되고, 이후엔 손절·목표 규칙대로만 청산됩니다. 성적표: `reports/paper.md`.
